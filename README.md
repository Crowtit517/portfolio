## ❯ About

제조 공정과 AI 에이전트의 접점에 관심이 많아 **Claude Code** 기반으로
AI 팩토리 제조 에이전트를 직접 만들고 있습니다.
이 저장소는 그 여정을 소개하는 개인 포트폴리오 사이트입니다.

## ❯ Live Demo

**[crowtit517.github.io/portfolio](https://crowtit517.github.io/portfolio/)**

GitHub Pages로 배포되어 있으며, `main` 브랜치에 푸시하면 자동으로 반영됩니다.

## ❯ Design

| | |
|---|---|
| 컨셉 | 제조(Manufacturing) × AI 듀오톤 |
| 포인트 컬러 | 앰버 `#ff9142` · 사이언 `#3ac2ff` |
| 폰트 | JetBrains Mono (제목) · Inter (본문) |
| 인터랙션 | 링크 호버 시 `❯` 프롬프트 커서가 슬라이드 인 |

## ❯ Tech Stack

- HTML5 / CSS3 (프레임워크 없이 단일 파일로 구성)
- Vanilla JavaScript — `IntersectionObserver` 기반 스크롤 등장 애니메이션
- GitHub Pages — 정적 호스팅

## ❯ Structure

```
portfolio/
├── index.html     # 사이트 전체 (HTML + CSS + JS 단일 파일)
├── preview.png    # README용 미리보기 이미지
└── .nojekyll      # GitHub Pages에서 Jekyll 처리 건너뛰기
```

## ❯ Run locally

```bash
git clone https://github.com/Crowtit517/portfolio.git
cd portfolio
python -m http.server 8000
# http://localhost:8000 접속
```
